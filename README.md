# AgroStat ANOVA Dataset

## Overview

This repository contains the dataset used to evaluate the statistical analysis features of **AgroStat**, a tool for agricultural data analysis using Analysis of Variance (ANOVA).

## Dataset Description

- **Genotype entries:** 15 (G1–G15)
- **Replications:** 3
- **Total observations:** 45
- **Experimental design:** Randomized Block Design (RBD) analysis framework
- **File format:** Excel (`.xlsx`)

## Traits Included

The dataset contains the following traits:

- PH
- LL
- MRP
- SFR
- GRW
- DRWR
- GYPP

The original dataset uses genotype codes (G1–G15). Additional information identifying the specific varieties or their pedigrees was not available in the supplied dataset.

## Purpose

The dataset was used to evaluate AgroStat's analytical outputs, including ANOVA results, treatment means, diagnostic assessments, treatment comparisons, and genetic parameter evaluation.

## Reproducibility

The Excel file is provided to support transparency and reproducibility of the analyses reported in the associated article.
